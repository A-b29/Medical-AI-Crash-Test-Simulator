# Model Flow, Interview Questions, and Resume Evidence

## Model flow

```text
Educational tabular dataset
  -> stratified train / validation / test split
  -> training-only scaler + logistic-regression fit
  -> fixed test predictions
  -> three severity-controlled perturbation branches
  -> task metrics + stability + reliability
  -> validation-selected abstention threshold
  -> immutable test evaluation + JSON/CSV/Markdown report
```

## Questions to prepare for

1. How did you avoid data leakage?  All preprocessing and perturbation reference statistics use only training data, while abstention threshold selection uses validation data only.
2. Why treat prediction stability separately from accuracy?  A model can be consistently wrong; comparing to the baseline prediction quantifies sensitivity, not clinical correctness.
3. How is feature dropout reproducible?  It is generated by NumPy’s seeded random generator, and the seed and severity are part of the run configuration.
4. What would you change for production evaluation?  Replace the educational dataset adapter, add governance and data contracts, evaluate natural distribution shifts, report confidence intervals, and conduct domain-specific validation.

## Resume evidence

After a measured run, a defensible bullet is: “Built a reproducible ML stress-testing pipeline with three deterministic perturbation families, calibration analysis, and validation-selected abstention evaluation; exported versioned JSON/CSV/Markdown experiment artifacts.” Include measured sample counts or runtimes only from your generated reports.
